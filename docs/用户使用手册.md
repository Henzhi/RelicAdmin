## 1. 产品概述

### 1.1 产品简介

RelicAdmin 是一个基于 Web 的文物数字化管理平台，旨在帮助博物馆和文化机构高效管理文物资产、审核用户生成内容、控制多角色权限，以及进行数据备份恢复。

### 1.2 系统架构

```
┌──────────────────────────────────────────────────┐
│                  浏览器（用户端）                    │
│            Chrome / Edge / Firefox                 │
└──────────────────────┬───────────────────────────┘
                       │ HTTP / WebSocket
┌──────────────────────┴───────────────────────────┐
│              Spring Boot 后端服务                   │
│          RESTful API + JWT 鉴权                     │
└──────────┬──────────────┬────────────────────────┘
           │              │
    ┌──────▼──────┐  ┌────▼──────┐
    │  MySQL 8.0  │  │  Redis    │
    │  (数据库)    │  │  (缓存)   │
    └─────────────┘  └───────────┘
```

### 1.3 用户角色说明

| 角色 | 权限范围 | 适用人员 |
|------|---------|---------|
| 超级管理员 | 全部功能 | 系统管理员 |
| 内容审核员 | 审核管理、违规处罚、申诉处理 | 内容审核人员 |
| 数据管理员 | 文物 CRUD、博物馆/艺术家/朝代管理 | 文物数据录入员 |
| 知识服务用户 | 知识图谱子系统 | 知识服务人员 |
| 掌上博物馆用户 | 掌上博物馆子系统 | 博物馆运营人员 |

### 1.4 运行环境要求

| 环境 | 要求 |
|------|------|
| 浏览器 | Chrome 90+ / Edge 90+ / Firefox 88+ |
| 屏幕分辨率 | 建议 1920×1080 或更高 |
| 网络 | 需要连接到后端服务器 |

## 2. 安装部署指南

### 2.1 环境准备

在部署 RelicAdmin 之前，请确保服务器已安装以下软件：

| 软件 | 版本要求 | 下载地址 |
|------|---------|---------|
| JDK | 17+ | https://adoptium.net |
| Maven | 3.6+ | https://maven.apache.org |
| MySQL | 8.0+ | https://dev.mysql.com/downloads |
| Redis | 6.x+ | https://redis.io/download |
| Node.js | 16+ | https://nodejs.org |

### 2.2 数据库初始化

**步骤 1：创建数据库**

```sql
CREATE DATABASE IF NOT EXISTS relic_admin
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

**步骤 2：执行迁移脚本**

按顺序执行 `relic-server/src/main/resources/db/migration/` 目录下的 SQL 文件：

```
V1__admin_user_system.sql       → 管理员账户体系 + 角色种子数据
V2__audit_strategies.sql        → 审核策略配置表
V3__backup_system.sql           → 备份策略与记录表
V4__crawl_task_module.sql       → 爬取任务模块
V5__system_config_module.sql    → 系统配置模块
V6__field_fix_and_feature_toggle.sql → 字段修复与功能开关
V7__monitoring_dashboard.sql    → 监控仪表盘
```

**步骤 3：验证默认管理员**

执行 V1 脚本后，会自动创建默认管理员账号：

| 用户名 | 密码 | 角色 |
|--------|------|------|
| `admin` | `admin123` | 超级管理员 |

> ⚠️ **重要**：首次登录后请立即修改默认密码。

### 2.3 后端配置

编辑 `relic-server/src/main/resources/application-dev.yml`，修改以下配置：

```yaml
relic:
  datasource:
    host: 你的数据库地址         # 例如：localhost 或 192.168.1.100
    port: 3306
    database: relic_admin
    username: 你的数据库用户名
    password: 你的数据库密码

  alioss:
    endpoint: oss-cn-beijing.aliyuncs.com     # 阿里云 OSS 地域
    access-key-id: 你的AccessKeyId
    access-key-secret: 你的AccessKeySecret
    bucket-name: 你的Bucket名称

  redis:
    host: 你的Redis地址
    port: 6379
    password: 你的Redis密码
    database: 0
```

### 2.4 启动后端服务

```bash
# 在项目根目录执行
mvn clean compile -pl relic-server -am

# 启动（开发模式）
mvn spring-boot:run -pl relic-server
```

启动成功后，在浏览器访问 `http://你的服务器地址:8080/doc.html` 可看到 API 文档页面。

### 2.5 启动前端服务

```bash
cd relic-frontend

# 安装依赖（首次执行）
npm install

# 启动开发服务器
npm run dev
```

### 2.6 生产环境部署

**后端打包**：

```bash
mvn clean package -pl relic-server -am -DskipTests
java -jar relic-server/target/relic-server-1.0-SNAPSHOT.jar --spring.profiles.active=prod
```

**前端打包**：

```bash
cd relic-frontend
npm run build
# 将 dist/ 目录部署到 Nginx 或 Apache
```

**Nginx 配置示例**：

```nginx
server {
    listen 80;
    server_name relic-admin.example.com;

    location / {
        root /var/www/relic-admin/dist;
        index index.html;
        try_files $uri /index.html;
    }

    location /admin/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 4. 功能模块操作说明

### 4.1 登录与退出

#### 登录

1. 打开浏览器访问系统登录页面
2. 输入用户名和密码
3. 点击「登录」按钮

> **注意**：登录成功后，系统会返回一个 Token（有效期 2 小时），过期后需要重新登录。

#### 退出登录

1. 点击页面右上角用户名旁的下拉菜单
2. 选择「退出登录」
3. 确认退出后返回登录页面

#### 忘记密码

请联系系统管理员重置密码。管理员可在「管理员管理」中重置任意用户的密码。

### 4.2 仪表盘

仪表盘是登录后的默认首页，展示系统关键数据的统计概览。

| 区域 | 内容 |
|------|------|
| 数据概览卡片 | 总文物数、总用户数、待审核数、今日新增数 |
| 文物总量趋势 | 折线图，按月统计文物新增情况 |
| 用户活跃度 | 柱状图，按日统计登录/注册/操作数 |
| 审核统计 | 饼图，已通过/待审核/已驳回占比 |
| 违规类型分布 | 环形图，各违规类型数量占比 |

### 4.3 权限管理

权限管理包含三个子模块：**管理员管理**、**角色管理**、**权限管理**。

#### 4.3.1 管理员管理

**查看管理员列表**：
1. 侧边栏点击「权限管理」→「管理员管理」
2. 页面显示管理员列表（用户名、真实姓名、邮箱、状态、创建时间）

**新增管理员**：
1. 点击「新增」按钮
2. 填写用户名、密码、真实姓名、邮箱、手机号
3. 选择角色（可多选）
4. 点击「保存」

**编辑管理员**：
1. 在列表中找到目标管理员
2. 点击「编辑」
3. 修改信息（真实姓名、邮箱、手机号、角色）
4. 点击「保存」

**删除管理员**：
1. 点击「删除」按钮
2. 在确认对话框中点击「确定」

> ⚠️ **注意**：不能删除自己的账号。

**重置密码**：
1. 点击「重置密码」按钮
2. 输入新密码
3. 点击「确定」

#### 4.3.2 角色管理

**查看角色列表**：
1. 侧边栏点击「权限管理」→「角色管理」
2. 页面显示角色列表（角色名称、编码、描述、创建时间）

**新增角色**：
1. 点击「新增」按钮
2. 填写角色名称、编码、描述
3. 选择该角色拥有的权限（可多选）
4. 点击「保存」

**编辑角色**：
1. 点击「编辑」按钮
2. 修改角色信息或权限配置
3. 点击「保存」

#### 4.3.3 权限管理

**查看权限列表**：
1. 侧边栏点击「权限管理」→「权限管理」
2. 页面显示权限列表（权限名称、编码、描述、父级权限）

**新增权限**：
1. 点击「新增」按钮
2. 填写权限名称、编码、描述
3. 选择父级权限（可选）
4. 点击「保存」

> **权限编码规则**：建议使用 `模块:操作` 格式，如 `artifact:create`、`audit:approve`。

### 4.4 内容管理（文物管理）

内容管理包含文物及其关联数据的管理。

#### 4.4.1 文物管理

**查看文物列表**：
1. 侧边栏点击「内容管理」→「文物管理」
2. 页面显示文物列表，支持按名称、博物馆、朝代、类型、状态筛选

**新增文物**：
1. 点击「新增文物」按钮
2. 填写文物信息：
   - 名称（必填）
   - 描述（可选）
   - 选择博物馆（必填）
   - 选择朝代（可选）
   - 选择艺术家（可选）
   - 选择地点（可选）
   - 选择文物类型（可选）
3. 点击「保存」

**编辑文物**：
1. 在列表中找到目标文物
2. 点击「编辑」
3. 修改需要变更的信息
4. 点击「保存」

**管理文物图片**：
1. 在文物列表点击「图片管理」按钮
2. 进入图片管理页面
3. 点击「上传图片」或拖拽图片到上传区域
4. 支持的图片格式：JPG、PNG、GIF、WebP
5. 单张图片最大 10MB
6. 图片上传后自动存储到阿里云 OSS

**删除文物**：
1. 点击「删除」按钮
2. 确认删除（文物及关联图片将被同时删除）

#### 4.4.2 博物馆管理

1. 侧边栏点击「内容管理」→「博物馆管理」
2. 支持新增、编辑、删除博物馆信息
3. 博物馆信息包括：名称、地址、联系方式、简介

#### 4.4.3 朝代管理

1. 侧边栏点击「内容管理」→「朝代管理」
2. 支持新增、编辑、删除朝代信息
3. 朝代信息包括：名称、起始年份、结束年份、描述

#### 4.4.4 艺术家管理

1. 侧边栏点击「内容管理」→「艺术家管理」
2. 支持新增、编辑、删除艺术家信息
3. 艺术家信息包括：姓名、生平简介、所属朝代

#### 4.4.5 地点管理

1. 侧边栏点击「内容管理」→「地点管理」
2. 支持新增、编辑、删除地点信息
3. 地点信息包括：名称、省份、城市、详细地址

#### 4.4.6 文物类型管理

1. 侧边栏点击「内容管理」→「文物类型管理」
2. 支持新增、编辑、删除文物类型
3. 类型信息包括：名称、描述

### 4.5 内容安全审核

内容安全模块用于管理用户生成内容（UGC）的审核、违规处罚和申诉处理。

#### 4.5.1 审核管理

**查看审核列表**：
1. 侧边栏点击「内容安全」→「审核管理」
2. 页面展示待审核/已审核内容列表
3. 支持按内容类型（动态/评论/上传）切换 Tab

**审核通过**：
1. 找到待审核的内容
2. 点击「通过」按钮
3. 内容将正常发布显示

**审核驳回**：
1. 找到待审核的内容
2. 点击「驳回」按钮
3. 填写驳回理由
4. 点击「确定」

**批量审核**：
1. 勾选多条待审核记录
2. 点击「批量通过」或「批量驳回」
3. 填写审核意见（批量驳回时必填）
4. 点击「确定」

#### 4.5.2 审核策略管理

**查看策略列表**：
1. 侧边栏点击「内容安全」→「审核策略」
2. 页面显示审核策略列表（内容类型、审核模式、风险阈值、状态）

**新增审核策略**：
1. 点击「新增」按钮
2. 选择内容类型：动态（post）/ 评论（comment）/ 上传（upload）
3. 选择审核模式：
   - **自动通过**：内容无敏感词直接发布
   - **人工审核**：所有内容需管理员审核
   - **自动驳回**：检测到敏感词自动驳回
4. 设置风险阈值（1-5，超过阈值的内容转人工审核）
5. 点击「保存」

> **配置示例**：动态审核策略 → 人工审核 → 风险阈值 3 → 敏感词风险 ≤3 自动通过，>3 转人工审核。

#### 4.5.3 敏感词管理

**查看敏感词列表**：
1. 侧边栏点击「内容安全」→「敏感词管理」
2. 页面显示敏感词列表（词语、类别、风险等级、创建时间）

**新增敏感词**：
1. 点击「新增」按钮
2. 输入敏感词
3. 选择类别（政治/色情/暴力/广告/其他）
4. 选择风险等级（1-5）
5. 点击「保存」

**编辑敏感词**：
1. 点击「编辑」按钮
2. 修改词语、类别或风险等级
3. 点击「保存」

**删除敏感词**：
1. 点击「删除」按钮
2. 确认删除

> **注意**：敏感词修改后将实时生效，无需重启服务。

#### 4.5.4 违规处罚管理

**查看处罚记录**：
1. 侧边栏点击「内容安全」→「违规处罚」
2. 页面显示处罚记录列表（用户、违规类型、处罚方式、处罚时间、状态）

**新增处罚**：
1. 点击「新增处罚」按钮
2. 选择目标用户
3. 选择违规类型
4. 选择处罚方式（禁言/封号/内容下架等）
5. 设置处罚期限（永久/自定义天数）
6. 填写处罚原因
7. 点击「保存」

**撤销处罚**：
1. 找到目标处罚记录
2. 点击「撤销处罚」按钮
3. 填写撤销原因
4. 点击「确定」

#### 4.5.5 申诉管理

**查看申诉列表**：
1. 侧边栏点击「内容安全」→「申诉管理」
2. 页面显示申诉列表（申诉人、申诉理由、申诉时间、状态）

**通过申诉**：
1. 点击「通过」按钮
2. 系统自动撤销对应处罚
3. 用户恢复正常状态

**驳回申诉**：
1. 点击「驳回」按钮
2. 填写驳回理由
3. 处罚继续执行

#### 4.5.6 违规类型管理

1. 侧边栏点击「内容安全」→「违规类型」
2. 支持新增、编辑、删除违规类型
3. 违规类型示例：发布违规内容、恶意刷屏、人身攻击、广告营销等

### 4.6 用户行为管理

用户行为管理用于查看和追踪前台用户的操作行为。

| 子模块 | 路径 | 功能 |
|--------|------|------|
| 用户收藏 | 用户行为 → 用户收藏 | 查看用户收藏的文物列表 |
| 用户点赞 | 用户行为 → 用户点赞 | 查看用户点赞记录 |
| 用户评论 | 用户行为 → 用户评论 | 查看用户评论记录，支持删除 |
| 用户关注 | 用户行为 → 用户关注 | 查看用户关注关系 |
| 用户上传 | 用户行为 → 用户上传 | 查看用户上传的文件记录 |
| 浏览历史 | 用户行为 → 浏览历史 | 查看用户浏览文物的历史记录 |
| 行为日志 | 用户行为 → 行为日志 | 查看用户详细操作日志 |

**通用操作**：
- 所有列表支持按用户、时间范围筛选

## 5. 常见问题解答（FAQ）

### Q1：登录时提示"用户名或密码错误"怎么办？

**A**：请检查：
1. 用户名拼写是否正确（区分大小写）
2. 密码拼写是否正确（区分大小写）
3. 账号是否被禁用（联系管理员）
4. 如忘记密码，联系管理员重置

### Q2：Token 过期后怎么处理？

**A**：Token 有效期为 2 小时。过期后系统会自动跳转到登录页面，重新登录即可。如果正在编辑内容，建议先保存草稿。

### Q3：为什么某些菜单看不到？

**A**：菜单显示根据当前登录用户的角色权限决定。如果您需要访问某些功能但看不到菜单，请联系超级管理员为您分配相应角色。

### Q4：上传图片失败怎么办？

**A**：请检查：
1. 图片格式是否为 JPG/PNG/GIF/WebP
2. 图片大小是否超过 10MB
3. 网络连接是否正常
4. 如果仍然失败，可能是 OSS 服务配置异常，联系管理员

### Q5：为什么有些操作提示"没有权限"？

**A**：您的角色没有该操作的权限。请联系超级管理员为您分配包含该权限的角色。

### Q6：如何批量导入数据？

**A**：目前支持以下批量导入方式：
- 敏感词：通过「敏感词管理」页面导入
- 文物数据：暂不支持批量导入，建议逐条添加

### Q7：审核策略如何配置才能生效？

**A**：
1. 进入「内容安全」→「审核策略」
2. 新增或编辑策略，选择内容类型和审核模式
3. 保存后策略立即生效，无需重启
4. 一个内容类型只能有一个生效的策略

### Q8：备份文件存储在哪里？

**A**：备份文件存储在服务器本地磁盘，路径由 `application.yml` 中的备份配置决定。备份文件支持下载到本地，也支持加密存储。

### Q9：可以同时使用多个浏览器登录同一个账号吗？

**A**：可以。但请注意，在一个浏览器中修改密码后，其他浏览器的 Token 仍然有效直到过期，建议修改密码后退出所有浏览器的登录。

### Q10：系统支持哪些浏览器？

**A**：系统已在以下浏览器中通过测试：
- Google Chrome 90+
- Microsoft Edge 90+
- Mozilla Firefox 88+
- 不推荐使用 Internet Explorer

## 6. 故障排除

### 6.1 前端页面无法加载

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 页面空白 | 前端服务未启动 | 执行 `cd relic-frontend && npm run dev` |
| 页面显示"无法连接到服务器" | 后端服务未启动 | 执行 `mvn spring-boot:run -pl relic-server` |
| 接口请求 404 | 接口路径错误 | 检查 API 文档 `http://localhost:8080/doc.html` |
| 控制台报 CORS 错误 | 跨域配置问题 | 检查后端 WebMvcConfiguration 跨域配置 |

### 6.2 登录相关故障

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 登录后立即跳回登录页 | Token 获取失败 | 打开浏览器开发者工具，查看登录接口响应 |
| 登录时提示 500 错误 | 数据库连接失败 | 检查数据库连接配置和数据库服务状态 |
| 无法获取验证码 | — | 当前版本未使用验证码，请直接输入用户名密码 |

### 6.3 数据库相关故障

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 启动报错 `Access denied for user` | 数据库用户名/密码错误 | 检查 `application-dev.yml` 中的数据库配置 |
| 启动报错 `Unknown database` | 数据库不存在 | 执行 `CREATE DATABASE relic_admin` |
| 启动报错 `Table doesn't exist` | 未执行迁移脚本 | 按顺序执行 `db/migration/` 目录下的 SQL 文件 |
| 中文乱码 | 字符集不匹配 | 检查数据库字符集是否为 `utf8mb4` |

### 6.4 文件上传故障

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 上传失败 | OSS 配置错误 | 检查 `application-dev.yml` 中的 OSS 配置 |
| 上传超时 | 网络不稳定 | 减小图片大小或检查网络 |
| 图片无法预览 | OSS Bucket 权限问题 | 检查 Bucket 是否设置为公共读 |

### 6.5 Redis 相关故障

| 现象 | 可能原因 | 解决方法 |
|------|---------|---------|
| 启动报错 Redis 连接失败 | Redis 服务未启动 | 启动 Redis 服务 |
| 缓存数据不一致 | 缓存未刷新 | 重启后端服务或在管理页面手动刷新缓存 |

### 6.6 日志查看

当系统出现异常时，可以通过以下方式查看日志：

1. **后端日志**：查看控制台输出或 `logs/` 目录下的日志文件
2. **前端日志**：打开浏览器开发者工具（F12），查看 Console 和 Network 标签
3. **操作日志**：登录系统后，进入「系统管理」→「操作日志」查看
